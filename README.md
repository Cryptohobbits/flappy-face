# Flappy Face

A tiny, original tap-to-flap browser game. Put your own face on the bird!

**Play:** https://cryptohobbits.github.io/flappy-face/

- Tap / click / Space to flap. M = mute, P/Esc = pause.
- "Take selfie" (front camera) or "Choose photo", then drag / pinch / scroll to position your face in the circle.
- Your photo is processed entirely in your browser and never uploaded. A 160px circular crop is kept in this device's localStorage; "Reset face" removes it.
- All art is drawn in code with canvas shapes; sounds are generated with the Web Audio API. No external assets, no build step.
